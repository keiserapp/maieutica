# Maieutica

**Maieutica is a tutor that asks what you want to learn, reads your sources, and teaches you one step at a time.**
Every step is a document you keep. Nothing is graded.

- **Download page:** https://getmaieutica.com, its only address.
- **Releases:** the [Releases](https://github.com/keiserapp/maieutica/releases) of this repository. Every version stays
  there with its notes and SHA-256 checksums; a file is never replaced under the same version.
- **Needs:** a Claude account from Anthropic (a paid Claude plan, or your own Anthropic API key).

This repository holds the download page and the releases, never the source. Made by Richard Keiser, Zurich.

The page is generated in the source repository (`site/`) and copied here; edit it there, not here.
